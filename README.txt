
Dominoes (Double-6) - Pygame GUI
==================================

Files:
- domino_game_pygame.py   -> main game file
- images/                 -> contains 28 PNG tiles (tile_0_0.png ... tile_6_6.png)

Run:
1. Install pygame: pip install pygame
2. Run: python3 domino_game_pygame.py

Notes:
- Images are pre-generated and included.
- If you want larger/smaller tiles, edit TILE_W/TILE_H in the python file.
